Guided workflows

Start with the design job, not the tool list.

Pick an outcome and move through the FDS tools in a practical order. Each workflow lists the inputs to gather, the tools to open, and the files to export when the job is ready.

Best for

Freelancers packaging client work Founders creating launch assets Designers preparing developer handoff Creators reusing assets across channels
01

Launch a Brand

Create a usable brand foundation with logo, colors, type, favicon, and a downloadable guide.

  1. Define: name, industry, mood, audience.
  2. Make: logo concepts, color palette, type pairing.
  3. Package: brand kit, favicon, business card.
Open Workflow -> Logo Concepts -> Palette -> Brand Kit ->
02

Build a Landing Page

Move from offer and content structure into responsive sections, OG images, and basic SEO assets.

  1. Plan: page goal, audience, sections, call to action.
  2. Build: layout, forms, supporting graphics.
  3. Export: HTML, OG image, favicon, sitemap.
Open Workflow -> Landing Builder -> OG Image -> Sitemap ->
03

Prepare a Social Campaign

Create channel-ready images with consistent brand, dimensions, and preview metadata.

  1. Collect: brand assets, message, campaign variants.
  2. Create: social templates, resized images, backgrounds.
  3. Export: PNG/JPEG/WebP variants and link previews.
Open Workflow -> Social Templates -> Resize -> Convert ->
04

Create a UI Kit

Turn tokens, components, forms, and interaction states into a consistent starter kit.

  1. Set: tokens, color roles, typography, spacing.
  2. Assemble: components, forms, layout patterns.
  3. Handoff: specs, CSS variables, Tailwind config.
Open Workflow -> Tokens -> Components -> Handoff ->
05

Make a Pitch Deck

Move from deck structure into slides, mockups, charts, and a presentable export.

  1. Outline: audience, problem, proof, ask.
  2. Create: deck, device mockups, supporting images.
  3. Present: export slideshow or pitch format.
Open Workflow -> Pitch Deck -> Mockups -> Slides ->
06

Clean and Export Assets

Prepare raw images, SVGs, icons, and stock assets for production use.

  1. Source: upload, browse, or generate assets.
  2. Clean: remove backgrounds, optimize SVG, resize.
  3. Export: final formats with clear naming.
Open Workflow -> Asset Library -> Background -> SVG Clean ->
